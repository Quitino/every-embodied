#### 1. 简介

动力学研究机器人运动与产生该运动所需的力/力矩之间的关系。它分为：

- **正动力学:** 给定力矩，计算加速度/运动轨迹。
- **逆动力学:** 给定运动轨迹（位置、速度、加速度），计算所需关节力矩（用于控制）。

最常用的建模方法是 **拉格朗日法 (Euler-Lagrange)**，它基于能量守恒。

#### 2. 核心公式

拉格朗日函数 $L$ 定义为系统总动能 $K$ 与总势能 $P$ 之差：

$$L(q, \dot{q}) = K(q, \dot{q}) - P(q)$$

动力学方程（欧拉-拉格朗日方程）：

$$\frac{d}{dt} \left( \frac{\partial L}{\partial \dot{q}_i} \right) - \frac{\partial L}{\partial q_i} = \tau_i$$

最终通常整理为标准的机器人在动力学形式：

$$M(q)\ddot{q} + C(q, \dot{q})\dot{q} + G(q) = \tau$$

- $M(q)$: 惯性矩阵 (Mass Matrix)
- $C(q, \dot{q})$: 科里奥利力和离心力项
- $G(q)$: 重力项

#### 3. 架构流程 (Mermaid)

```Mermaid

```

#### 4. Python 代码验证 (SymPy 符号推导)

动力学推导非常繁琐，使用 Python 的符号计算库 `sympy` 可以完美演示这一过程。以下演示推导一个简单**单摆**的动力学方程。



```Python
import sympy as sp

# 1. 定义符号
t = sp.symbols('t')
m, l, g = sp.symbols('m l g', real=True, positive=True)
theta = sp.Function('theta')(t)  # 关节角度随时间变化

# 定义速度 (theta_dot) 和 加速度 (theta_ddot)
theta_dot = theta.diff(t)
theta_ddot = theta_dot.diff(t)

# 2. 计算能量
# 动能 K = 1/2 * m * v^2。对于单摆，v = l * angular_velocity
v = l * theta_dot
K = sp.Rational(1, 2) * m * v**2

# 势能 P = m * g * h。假设最低点势能为0，则 h = l * (1 - cos(theta))
# 或者简单定义坐标原点在转轴，y轴向上，则 h = -l * cos(theta)
h = -l * sp.cos(theta)
P = m * g * h

# 3. 拉格朗日函数 L
L = K - P

# 4. 欧拉-拉格朗日方程
# d/dt (dL/d_theta_dot)
dL_dthetadot = sp.diff(L, theta_dot)
term1 = sp.diff(dL_dthetadot, t)

# dL/d_theta
term2 = sp.diff(L, theta)

# 力矩 tau = term1 - term2
tau = term1 - term2

# 5. 简化并打印结果
equation = sp.simplify(tau)
print("--- 自动推导的动力学方程 (Tau = ...) ---")
sp.pprint(equation)

print("\n--- 提取各项 ---")
# 对于单摆: M*q_ddot + G = 0 (无阻尼情况)
# 我们期望看到 M = m*l^2, G = m*g*l*sin(theta)
print(f"惯性项 (对应 theta_ddot): {equation.coeff(theta_ddot)}")
# 注意：sympy提取非线性项比较复杂，这里人工观察打印结果即可验证
# 理论结果应为: m * l**2 * theta_ddot + m * g * l * sin(theta)
```

#### 5. 理论深挖：从最速曲线到欧拉-拉格朗日方程

> **目标：** 从一道经典物理竞赛题出发，一路推导到机器人动力学方程 $M\ddot{q}+C\dot{q}+G=\tau$。

---

##### 5.1 最速曲线问题 — 变分法的起源

**1696 年，约翰·伯努利向全欧洲数学家发出挑战：**

> 在竖直平面内，A 和 B 两点之间（B 在 A 的右下方），用什么形状的光滑轨道，能让小球仅靠重力从 A 滑到 B 的**时间最短**？

直觉猜测是直线，但这不对——直线距离最短，但速度积累最慢。答案是先陡后缓的**摆线 (Cycloid)**。

**如何数学化描述这个问题？**

取 $y$ 轴向下为正，坐标原点在 A。

**第一步：用能量守恒求速度。**
小球从高度 0 下落到高度 $y$，势能减少 $mgy$，全部转化为动能：
$$\frac{1}{2}mv^2 = mgy \implies v = \sqrt{2gy}$$

**第二步：写出弧长微元。**
沿曲线 $y(x)$ 运动，弧长微元为（勾股定理）：
$$ds = \sqrt{dx^2 + dy^2} = \sqrt{1 + \left(\frac{dy}{dx}\right)^2}\,dx = \sqrt{1 + y'^2}\,dx$$

**第三步：写出时间积分。**
时间 = 路程 ÷ 速度，积分得总时间：
$$T[y] = \int_0^{x_1} \frac{ds}{v} = \int_0^{x_1} \frac{\sqrt{1+y'^2}}{\sqrt{2gy}}\,dx$$

**关键观察：** 这里 $T$ 的输入是一整条曲线 $y(x)$，输出是一个数（时间）。这不是普通函数——我们叫它**泛函 (Functional)**。

---

##### 5.2 泛函：函数的函数

| 概念 | 输入 | 输出 | 记号 |
|------|------|------|------|
| 普通函数 | 一个数 $x$ | 一个数 | $f(x)$ |
| **泛函** | 一整个函数 $y(x)$ | 一个数 | $S[y]$ |

最速曲线的目标：在所有连接 A、B 的曲线 $y(x)$ 中，找到使 $T[y]$ 最小的那一条。

**一般形式的泛函（本节的研究对象）：**
$$S[y] = \int_a^b f\!\left(y(x),\; y'(x),\; x\right) dx$$
其中 $f$ 是已知函数（对应最速曲线：$f = \frac{\sqrt{1+y'^2}}{\sqrt{2gy}}$）。

我们要找：**什么样的 $y(x)$ 能让 $S[y]$ 取极值？**

---

##### 5.3 推导欧拉-拉格朗日方程

**思路：** 模仿普通函数极值（$f'(x^*)=0$），对最优路径做"微小扰动"，令扰动带来的一阶变化为零。

---

**第一步：设定最优路径与扰动。**

设 $y^*(x)$ 是使 $S$ 取极值的最优曲线。考虑所有"邻近"曲线：
$$y(x,\varepsilon) = y^*(x) + \varepsilon\,\eta(x)$$

- $\varepsilon$ 是一个很小的实数（扰动幅度）
- $\eta(x)$ 是任意光滑函数，代表扰动的"形状"
- **端点固定：** $\eta(a)=0$，$\eta(b)=0$（出发点和终点不能动）

  > **为什么端点必须固定？**
  >
  > 我们的问题本身就规定了"从 A 出发、到 B 结束"——这是**约束条件**，不是待优化的对象。
  > 我们只有权利选择中间走哪条路，没有权利改变起点和终点。
  >
  > 换句话说：$y^*(a) = y_A$，$y^*(b) = y_B$ 是固定的。扰动后的路径 $y^* + \varepsilon\eta$ 也必须满足同样的端点，因此：
  > $$y(a,\varepsilon) = y_A \implies y^*(a) + \varepsilon\,\eta(a) = y_A \implies \eta(a) = 0$$
  > $$y(b,\varepsilon) = y_B \implies y^*(b) + \varepsilon\,\eta(b) = y_B \implies \eta(b) = 0$$
  >
  > **这个条件在第四步（分部积分）中至关重要**：它使边界项
  > $\left[\frac{\partial f}{\partial y'}\cdot\eta\right]_{x=a}^{x=b} = \frac{\partial f}{\partial y'}\big|_b \cdot \underbrace{\eta(b)}_{0} - \frac{\partial f}{\partial y'}\big|_a \cdot \underbrace{\eta(a)}_{0} = 0$
  > 整个边界项消失，推导才能继续得到 E-L 方程。若端点不固定（$\eta(a)\neq0$ 或 $\eta(b)\neq0$），边界项不为零，会得到额外的**自然边界条件**，问题就变成另一类了。

当 $\varepsilon=0$ 时，$y(x,0) = y^*(x)$，即回到最优路径。

---

**第二步：把 $S$ 看成关于 $\varepsilon$ 的普通函数。**

$$S(\varepsilon) = \int_a^b f\!\left(y^*(x)+\varepsilon\eta(x),\;\; y^{*\prime}(x)+\varepsilon\eta'(x),\;\; x\right) dx$$

$y^*(x)$ 是极值，所以当 $\varepsilon=0$ 时 $S(\varepsilon)$ 取极值，意味着：
$$\frac{dS}{d\varepsilon}\bigg|_{\varepsilon=0} = 0$$

---

**第三步：对 $S(\varepsilon)$ 求导（在积分号内用链式法则）。**

把 $f$ 看成 $\varepsilon$ 的复合函数，其中 $y = y^*+\varepsilon\eta$，$y' = y^{*\prime}+\varepsilon\eta'$：

$$\frac{d}{d\varepsilon}f(y,y',x) = \frac{\partial f}{\partial y}\cdot\frac{\partial y}{\partial\varepsilon} + \frac{\partial f}{\partial y'}\cdot\frac{\partial y'}{\partial\varepsilon} + \underbrace{\frac{\partial f}{\partial x}\cdot\frac{\partial x}{\partial\varepsilon}}_{=\;0,\;\text{因为}x\text{与}\varepsilon\text{无关}}$$

其中 $\frac{\partial y}{\partial\varepsilon} = \eta(x)$，$\frac{\partial y'}{\partial\varepsilon} = \eta'(x)$，所以：

$$\frac{dS}{d\varepsilon} = \int_a^b \left(\frac{\partial f}{\partial y}\cdot\eta + \frac{\partial f}{\partial y'}\cdot\eta'\right) dx$$

令其在 $\varepsilon=0$ 处等于零：
$$\int_a^b \left(\frac{\partial f}{\partial y}\cdot\eta + \frac{\partial f}{\partial y'}\cdot\eta'\right) dx = 0 \quad \cdots (*)$$

---

**第四步：分部积分，消去 $\eta'$。**

$(*)$ 式中第二项 $\int_a^b \frac{\partial f}{\partial y'}\cdot\eta'\,dx$ 含 $\eta'$，不方便处理。用分部积分：

$$\int u\,dv = [uv]_a^b - \int v\,du$$

令：
$$u = \frac{\partial f}{\partial y'}, \quad dv = \eta'(x)\,dx$$
则：
$$du = \frac{d}{dx}\!\left(\frac{\partial f}{\partial y'}\right) dx, \quad v = \eta(x)$$

代入：
$$\int_a^b \frac{\partial f}{\partial y'}\cdot\eta'\,dx = \underbrace{\left[\frac{\partial f}{\partial y'}\cdot\eta\right]_{x=a}^{x=b}}_{=\;0,\;\text{因为}\eta(a)=\eta(b)=0} - \int_a^b \eta(x)\cdot\frac{d}{dx}\!\left(\frac{\partial f}{\partial y'}\right) dx$$

所以：
$$\int_a^b \frac{\partial f}{\partial y'}\cdot\eta'\,dx = -\int_a^b \frac{d}{dx}\!\left(\frac{\partial f}{\partial y'}\right)\cdot\eta\,dx$$

---

**第五步：合并，提取公因子 $\eta$。**

代回 $(*)$：
$$\int_a^b \frac{\partial f}{\partial y}\cdot\eta\,dx - \int_a^b \frac{d}{dx}\!\left(\frac{\partial f}{\partial y'}\right)\cdot\eta\,dx = 0$$

$$\int_a^b \underbrace{\left[\frac{\partial f}{\partial y} - \frac{d}{dx}\!\left(\frac{\partial f}{\partial y'}\right)\right]}_{h(x)}\cdot\eta(x)\,dx = 0$$

---

**第六步：基本引理——方括号内必须恒为零。**

上式对**任意** $\eta(x)$ 都成立。假设 $h(x_0) \neq 0$ 于某点，那我们可以构造 $\eta(x)$ 在 $x_0$ 附近与 $h(x)$ 同号的小凸包，使积分 $> 0$，产生矛盾。因此：

$$h(x) \equiv 0 \quad \Longrightarrow \quad \boxed{\frac{d}{dx}\!\left(\frac{\partial f}{\partial y'}\right) - \frac{\partial f}{\partial y} = 0}$$

**这就是欧拉-拉格朗日方程。** 它是"泛函 $S[y]$ 取极值"的必要条件，地位等同于普通函数极值的 $f'=0$。

##### 5.4 哈密顿原理 — 把变分法嫁接到物理

**变量替换：** 把 $x \to t$（时间），$y(x) \to q(t)$（广义坐标），$y' \to \dot{q}$，$f \to L$。

**哈密顿原理（最小作用量原理）：**

> 力学系统从 $t_1$ 运动到 $t_2$，其真实发生的轨迹 $q(t)$ 使**作用量 (Action)**
> $$S[q] = \int_{t_1}^{t_2} L(q,\dot{q})\,dt$$
> 取极值（即 $\delta S = 0$）。

直接套用欧拉-拉格朗日方程（$x \to t$，$y \to q$，$y' \to \dot{q}$）：

$$\frac{d}{dt}\!\left(\frac{\partial L}{\partial \dot{q}}\right) - \frac{\partial L}{\partial q} = 0$$

若系统受外力 / 关节力矩 $\tau$（非保守力），右端补上 $\tau$：

$$\frac{d}{dt}\!\left(\frac{\partial L}{\partial \dot{q}}\right) - \frac{\partial L}{\partial q} = \tau$$

这正是文档开头给出的那个"奇怪公式"。

---

##### 5.5 为什么偏偏选 $L = K - P$？

**答：因为这个选择恰好让 E-L 方程退化成牛顿第二定律 $F = ma$。**

以一维质点（质量 $m$，坐标 $q$）在势场 $P(q)$ 中运动为例，**一步一步验证**：

**写出 $L$：**
$$L = K - P = \frac{1}{2}m\dot{q}^2 - P(q)$$

---

**计算 $\dfrac{\partial L}{\partial \dot{q}}$（对速度求偏导，$q$ 视为常数）：**

$$\frac{\partial L}{\partial \dot{q}}
= \frac{\partial}{\partial \dot{q}}\!\left(\frac{1}{2}m\dot{q}^2\right) - \frac{\partial P(q)}{\partial \dot{q}}
= \frac{1}{2}m \cdot 2\dot{q} - 0
= m\dot{q}$$

（$P$ 只依赖 $q$，不含 $\dot{q}$，偏导为零。）

---

**计算 $\dfrac{d}{dt}\!\left(\dfrac{\partial L}{\partial \dot{q}}\right)$（对时间求导）：**

$$\frac{d}{dt}(m\dot{q}) = m\ddot{q}$$

（$m$ 是常数，$\dot{q}$ 对 $t$ 求导得 $\ddot{q}$。）

---

**计算 $\dfrac{\partial L}{\partial q}$（对位置求偏导，$\dot{q}$ 视为常数）：**

$$\frac{\partial L}{\partial q}
= \frac{\partial}{\partial q}\!\left(\frac{1}{2}m\dot{q}^2\right) - \frac{\partial P(q)}{\partial q}
= 0 - \frac{\partial P}{\partial q}
= -\frac{\partial P}{\partial q}$$

（$\frac{1}{2}m\dot{q}^2$ 不含 $q$，偏导为零。）

注意：保守力的定义就是 $F = -\dfrac{\partial P}{\partial q}$，所以 $\dfrac{\partial L}{\partial q} = F$。

---

**代入 E-L 方程：**

$$\frac{d}{dt}\!\left(\frac{\partial L}{\partial \dot{q}}\right) - \frac{\partial L}{\partial q} = 0$$

$$m\ddot{q} - \left(-\frac{\partial P}{\partial q}\right) = 0$$

$$m\ddot{q} + \frac{\partial P}{\partial q} = 0$$

$$\boxed{m\ddot{q} = -\frac{\partial P}{\partial q} = F}$$

**这正是牛顿第二定律 $F=ma$！** 选 $L = K - P$ 恰好使 E-L 方程与牛顿力学等价。

---

##### 5.6 推广到 $n$ 关节机器人：$M$、$C$、$G$ 从哪里来？

多关节机器人有 $n$ 个广义坐标 $\mathbf{q} = [q_1, \ldots, q_n]^\top$。对每个关节 $k$ 分别写 E-L 方程：

$$\frac{d}{dt}\!\left(\frac{\partial L}{\partial \dot{q}_k}\right) - \frac{\partial L}{\partial q_k} = \tau_k, \quad k=1,\ldots,n$$

接下来逐项展开，**一步不跳**。

---

**5.6.1 动能的矩阵写法**

机器人每个连杆的动能（平动 + 转动）经过雅可比矩阵变换后，可以统一写成：
$$K = \frac{1}{2}\dot{\mathbf{q}}^\top M(\mathbf{q})\,\dot{\mathbf{q}}$$

$M(\mathbf{q})$ 是 $n \times n$ **正定对称**惯性矩阵，**它的元素依赖于关节角 $\mathbf{q}$**（手臂弯曲时惯量分布变化）。

展开为求和形式（方便逐项求偏导）：
$$K = \frac{1}{2}\sum_{i=1}^n \sum_{j=1}^n M_{ij}(\mathbf{q})\,\dot{q}_i\,\dot{q}_j$$

---

**5.6.2 计算 $\dfrac{\partial L}{\partial \dot{q}_k}$（等价于 $\dfrac{\partial K}{\partial \dot{q}_k}$，因为 $P$ 不含 $\dot{q}$）**

$$\frac{\partial K}{\partial \dot{q}_k}
= \frac{1}{2}\sum_{i,j} M_{ij} \cdot \frac{\partial (\dot{q}_i \dot{q}_j)}{\partial \dot{q}_k}$$

对乘积 $\dot{q}_i \dot{q}_j$ 关于 $\dot{q}_k$ 求偏导（链式法则）：
$$\frac{\partial (\dot{q}_i \dot{q}_j)}{\partial \dot{q}_k} = \delta_{ik}\,\dot{q}_j + \delta_{jk}\,\dot{q}_i$$
（$\delta_{ik}$ 是克罗内克符号：$i=k$ 时为 1，否则为 0）

代入：
$$\frac{\partial K}{\partial \dot{q}_k}
= \frac{1}{2}\sum_{i,j} M_{ij}\left(\delta_{ik}\,\dot{q}_j + \delta_{jk}\,\dot{q}_i\right)
= \frac{1}{2}\sum_j M_{kj}\,\dot{q}_j + \frac{1}{2}\sum_i M_{ik}\,\dot{q}_i$$

由于 $M$ 是对称矩阵（$M_{ik} = M_{ki}$），两项相等，合并：
$$\frac{\partial K}{\partial \dot{q}_k} = \sum_j M_{kj}(\mathbf{q})\,\dot{q}_j = [M(\mathbf{q})\,\dot{\mathbf{q}}]_k$$

即 $\dfrac{\partial L}{\partial \dot{\mathbf{q}}} = M(\mathbf{q})\,\dot{\mathbf{q}}$（向量形式）。

---

**5.6.3 计算 $\dfrac{d}{dt}\!\left(\dfrac{\partial L}{\partial \dot{q}_k}\right)$——这里出现 $M$ 和 $C$**

对 $[M(\mathbf{q})\,\dot{\mathbf{q}}]_k = \sum_j M_{kj}(\mathbf{q}(t))\,\dot{q}_j(t)$ 关于时间求导（乘积法则）：

$$\frac{d}{dt}\!\left(\sum_j M_{kj}\,\dot{q}_j\right)  = \sum_j \underbrace{\frac{d M_{kj}}{dt}}_{\text{①}}\,\dot{q}_j + \sum_j M_{kj}\,\underbrace{\ddot{q}_j}_{\text{②}}$$

**②** 项是 $[M(\mathbf{q})\,\ddot{\mathbf{q}}]_k$，即惯性矩阵乘以角加速度。

**① 项** 用链式法则展开（$M_{kj}$ 是 $\mathbf{q}(t)$ 的函数）：

$$\frac{d M_{kj}}{dt} = \sum_{l=1}^n \frac{\partial M_{kj}}{\partial q_l}\,\dot{q}_l$$

代入：
$$\text{① 部分} = \sum_j \left(\sum_l \frac{\partial M_{kj}}{\partial q_l}\,\dot{q}_l\right)\dot{q}_j = \sum_{j,l} \frac{\partial M_{kj}}{\partial q_l}\,\dot{q}_j\,\dot{q}_l$$

合并得：

$$\frac{d}{dt}\!\left(\frac{\partial L}{\partial \dot{q}_k}\right) = \underbrace{\sum_j M_{kj}\,\ddot{q}_j}_{[M\ddot{\mathbf{q}}]_k} + \underbrace{\sum_{j,l} \frac{\partial M_{kj}}{\partial q_l}\,\dot{q}_j\,\dot{q}_l}_{\text{待处理的"速度平方项"}} \quad \cdots (\text{A})$$

---

**5.6.4 计算 $\dfrac{\partial L}{\partial q_k}$——这里出现 $C$ 的另一半和 $G$**

$$\frac{\partial L}{\partial q_k} = \frac{\partial K}{\partial q_k} - \frac{\partial P}{\partial q_k}$$

**重力项**：$\dfrac{\partial P}{\partial q_k}$ 直接定义为 $G_k$，即 $G(\mathbf{q}) = \dfrac{\partial P}{\partial \mathbf{q}}$。

**动能对 $q_k$ 求偏导**（此时 $M_{ij}$ 依赖 $q_k$，$\dot{q}$ 视为常数）：

$$\frac{\partial K}{\partial q_k}
= \frac{1}{2}\sum_{i,j} \frac{\partial M_{ij}}{\partial q_k}\,\dot{q}_i\,\dot{q}_j \quad \cdots (\text{B})$$

---

**5.6.5 代入 E-L 方程，整理出 $C$**

E-L 方程：$\dfrac{d}{dt}\!\left(\dfrac{\partial L}{\partial \dot{q}_k}\right) - \dfrac{\partial L}{\partial q_k} = \tau_k$

代入 (A)、(B)：

$$[M\ddot{\mathbf{q}}]_k + \sum_{j,l} \frac{\partial M_{kj}}{\partial q_l}\,\dot{q}_j\,dot{q}_l - \frac{1}{2}\sum_{i,j} \frac{\partial M_{ij}}{\partial q_k}\,\dot{q}_i\,\dot{q}_j + \frac{\partial P}{\partial q_k} = \tau_k$$

将中间两个"速度平方"项合并（重新统一哑标名为 $j, l$）：

$$\text{速度耦合项} = \sum_{j,l}\underbrace{\left(\frac{\partial M_{kj}}{\partial q_l} - \frac{1}{2}\frac{\partial M_{jl}}{\partial q_k}\right)}_{\Gamma_{kjl}}\,\dot{q}_j\,\dot{q}_l$$

其中 $\Gamma_{kjl}$ 叫做**克里斯托费尔符号 (Christoffel Symbol)**，利用 $M$ 对称性可以化简为标准形式。定义矩阵 $C(\mathbf{q},\dot{\mathbf{q}})$：

$$C_{kj}(\mathbf{q},\dot{\mathbf{q}}) = \sum_{l=1}^n \Gamma_{kjl}\,\dot{q}_l$$

则速度耦合项 $= \sum_j C_{kj}\,\dot{q}_j = [C(\mathbf{q},\dot{\mathbf{q}})\,\dot{\mathbf{q}}]_k$。

最终，**对所有 $k$ 写成向量形式**：

$$\boxed{M(\mathbf{q})\,\ddot{\mathbf{q}} + C(\mathbf{q},\dot{\mathbf{q}})\,\dot{\mathbf{q}} + G(\mathbf{q}) = \boldsymbol{\tau}}$$

| $M\ddot{\mathbf{q}}$ | $\frac{d}{dt}(M\dot{q})$ 中的 $M\ddot{q}$ | 对抗加速度的惯性力 | 始终存在 |
| $C\dot{\mathbf{q}}$ | $\frac{dM}{dt}\dot{q}$ 展开的交叉速度项 | 科里奥利力（轴旋转带来的侧向力）+ 离心力 | 高速运动时 |
| $G(\mathbf{q})$ | $-\partial L/\partial q = \partial P/\partial q$ | 因姿态变化引起的重力矩 | 手臂非竖直时 |

##### 5.7 完整推导链（总览）

```
[1696年最速曲线问题]
   ↓  需要在所有路径中找"最优路径"
[泛函 S[y] = ∫f(y,y',x)dx]
   ↓  对最优路径施加微小扰动 y = y* + ε·η
   ↓  令 dS/dε|_{ε=0} = 0
   ↓  链式法则展开积分
   ↓  分部积分消去 η'
   ↓  由 η 任意性 → 被积函数恒为零
[欧拉-拉格朗日方程]  d/dx(∂f/∂y') - ∂f/∂y = 0
   ↓  替换 x→t, y→q, f→L（哈密顿原理）
[L 的 E-L 方程]  d/dt(∂L/∂q̇) - ∂L/∂q = τ
   ↓  令 L = K - P = ½mq̇² - P(q)
   ↓  验证：∂L/∂q̇ = mq̇，d/dt(·) = mq̈，∂L/∂q = -∂P/∂q = F
[≡ 牛顿第二定律]  mq̈ = F
   ↓  升维到 n 关节：K = ½q̇ᵀM(q)q̇
   ↓  对 ∂K/∂q̇ₖ 求和、对 d/dt(Mq̇) 用乘积法则
   ↓  dM/dt 展开 → 产生 Cq̇ 项
   ↓  ∂K/∂q 展开 → 与 dM/dt 项合并为 Christoffel 符号
[机器人动力学]  M(q)q̈ + C(q,q̇)q̇ + G(q) = τ
```
